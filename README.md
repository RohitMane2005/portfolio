# Portfolio Website

A modern, responsive personal portfolio website built using **HTML, CSS, and JavaScript**.  
This project showcases my skills, projects, and includes a fully functional contact form.

## 🚀 Features

- Responsive design (desktop, tablet, mobile)
- Glassmorphism UI with smooth animations
- Typing text animation in hero section
- Projects showcase section
- Contact form with **EmailJS**
- Google **reCAPTCHA** spam protection
- Loading spinner on form submit
- Toast notifications for success & error
- Accessible and clean UI

## 🛠 Tech Stack
- HTML5
- CSS3 (Flexbox & Grid)
- JavaScript (Vanilla)
- EmailJS
- Google reCAPTCHA
- Git & GitHub Pages
